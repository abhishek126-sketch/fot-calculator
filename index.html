FOT Reference Calculator

Predicted values, z-scores, and bronchodilator response for Forced Oscillation Technique. For clinical decision support only.

1. Patient & Measurement

Reference sets: Adults (≥18y) use Indian adult equations. Children (<18y) use the device-specific equations chosen in the selector.
*Warning: oscillometry reference equations are device-specific. Using equations from a different device may cause misdiagnosis.

1b. Smoking history

Cigarette pack-years = (cig/day ÷ 20) × years. Bidi/mixed reported as smoking index (sticks/day × years); no validated bidi↔cigarette pack-year equivalence is assumed. Cannabis = joint-years, kept separate. Sources shown on the PDF.

1c. Saved tests & Google Drive sync

Tests are stored in this browser first. Optional Google Drive sync keeps a backup in your Drive only (scope drive.file) so you can compare on other computers/phones. Nothing is uploaded to GitHub or any clinic server.

OAuth client ID not set in config.js. Create a Google Cloud Web client (Drive API + Testing consent with your Gmail as test user; authorized JavaScript origin https://abhishek126-sketch.github.io), paste the client ID into config.js, redeploy. No client secret is used.

ERS 2020: CoV of R5 <10% adults / <15% children. Disease flags (one-sided): R5, R5−Rxx, AX (and Fres when referenced) abnormal if z > +1.645 (above ULN); X5 abnormal if z < −1.645 (below LLN, more negative). Values on the other side of ±1.645 are outside the reference range but not obstruction signs. BDR: R5 ↓≥40%, X5 ↑≥50%, AX ↓≥80%.
